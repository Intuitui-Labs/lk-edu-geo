# @repo/lk-edu-geo

A robust, type-safe data package for Sri Lankan geographical and educational jurisdictions.

## Features

- **Dual-Hierarchy Mapping**: Seamlessly link Administrative (DS/GN) and Educational (Zone/Division) data.
- **10,000+ Schools**: Census-aligned school registry with metadata.
- **Hierarchical IDs**: Predictable ID system (`P_`, `D_`, `DS_`, `GN_`, `Z_`, `DIV_`, `SCH_`).
- **ESM/CJS Support**: Pre-bundled for modern web and legacy Node environments.

## Installation

```bash
pnpm add @repo/lk-edu-geo
```

## Quick Start

### Basic Lookups
```typescript
import { getProvinces, getDistricts, searchSchools } from '@repo/lk-edu-geo';

// Get all provinces
const provinces = getProvinces();

// Search for a school
const results = searchSchools('Royal College');
```

### Cross-Jurisdiction Bridge
```typescript
import { getHierarchyForSchool } from '@repo/lk-edu-geo';

const hierarchy = getHierarchyForSchool('SCH_0114001');
console.log(hierarchy.admin.district.name); // Colombo
console.log(hierarchy.edu.zone.name); // Colombo
```

### Direct Data Access
```typescript
import data from '@repo/lk-edu-geo/data';
console.log(data.schools.length);
```

## ID System Reference

| Prefix | Entity | Example |
| :--- | :--- | :--- |
| `P_` | Province | `P_01` (Western) |
| `D_` | District | `D_0101` (Colombo) |
| `DS_` | DS Area | `DS_010101` |
| `GN_` | GN Division | `GN_01010118` |
| `Z_` | Edu Zone | `Z_0101` |
| `DIV_` | Edu Division | `DIV_010101` |
| `SCH_` | School | `SCH_0114001` |

## Data Harvesting

Data is generated by consolidating school registry SQL chunks and administrative geographics.

```bash
pnpm run import:xlsx
```
